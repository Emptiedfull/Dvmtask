#Addition feature

The webapp allows the user to their now-playing song on their lastfm account

Since this endpoint is locked with auth access, it works by making the user login and then uses the acquired token and the shared secret in subsequent requests to act on the users behalf. 

It can be accesed by visiting [here](https://emptiedfull.hackclub.app/now-playing)
